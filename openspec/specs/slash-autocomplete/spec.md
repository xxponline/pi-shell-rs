# slash-autocomplete Specification

## Purpose

输入斜杠命令时提供即时候选提示：列出可用命令及说明、支持模糊过滤与键盘导航、一键应用或直接提交，使用户无需记忆 24 个命令名即可完成斜杠命令输入。

## Requirements

### Requirement: 斜杠命令候选触发与过滤

输入框中以 `/` 起始且尚未输入空格的文本 MUST 自动弹出补全菜单：候选为全部本地命令名，按输入（`/` 之后的文本）模糊过滤（多词元全部匹配才保留），无匹配时菜单自动收起；每个候选 MUST 显示说明列（有参数提示时为 `参数提示 — 说明`）。补全为纯本地行为，不产生任何 RPC。

#### Scenario: 输入即弹菜单

- **WHEN** 用户在空输入框键入 `/`
- **THEN** 输入区下方弹出候选菜单，列出全部本地命令及说明列

#### Scenario: 模糊过滤与无匹配

- **WHEN** 用户继续键入 `mod`
- **THEN** 菜单收敛为匹配项（含 `/model`）；键入不存在的 `zzz` 时菜单收起且不报错

#### Scenario: 消息中部的斜杠不触发

- **WHEN** 用户在非行首位置或已含空格的行中输入 `/`
- **THEN** 不弹出命令补全菜单，输入行为与普通文本一致

### Requirement: 菜单渲染与最佳匹配预选

补全菜单 MUST 渲染在输入区下方，最多同时显示 5 条，超出时可滚动并显示 `(当前/总数)` 计数；打开时 MUST 自动预选最佳匹配（精确匹配优先，其次第一个前缀匹配），选中项有可见高亮。

#### Scenario: 超出上限滚动

- **WHEN** `/` 弹出全部候选且条数超过 5
- **THEN** 显示前 5 条与 `(1/24)` 计数，↑↓ 移动时计数与可见窗口随之更新

#### Scenario: 自动预选最佳匹配

- **WHEN** 用户键入 `/thi`
- **THEN** `thinking` 项被预选（而非列表首项），高亮可见

### Requirement: 菜单键位与应用

菜单打开时：↑↓/PageUp/PageDown MUST 仅移动菜单选中项；Esc MUST 只关闭菜单（不清空输入、不提交）；Tab MUST 应用选中项（把 `/前缀` 替换为 `/命令名 `，光标置于空格后）并关闭菜单；**回车 MUST 先应用选中补全再立即提交该行**；继续输入会即时重过滤。菜单打开时除上述键外的编辑键仍作用于输入框。

#### Scenario: Tab 应用补全

- **WHEN** 菜单打开且 `thinking` 被选中时按 Tab
- **THEN** 输入框变为 `/thinking `，光标在空格后，菜单关闭且未提交

#### Scenario: 回车补全并提交

- **WHEN** 用户键入 `/thi`、菜单预选 `thinking`、按回车
- **THEN** 输入被补全为 `/thinking` 命令并立即按该命令执行（打开 thinking 选择器），输入框清空

#### Scenario: Esc 只关菜单

- **WHEN** 菜单打开时按 Esc
- **THEN** 菜单关闭，输入框内容与光标保持不变，不触发任何命令

### Requirement: 命令参数补全

`/model ` 与 `/thinking ` 输入空格后 MUST 弹出参数候选（分别为可用模型 `provider/id` 与可用 thinking 级别，模糊过滤），应用后替换参数部分；无参数补全能力的命令在空格后 MUST 不再弹出命令菜单。

#### Scenario: model 参数补全

- **WHEN** 输入 `/model ` 后继续键入模型名片段
- **THEN** 弹出匹配的模型候选，选择应用后参数部分被替换、光标位于其后

#### Scenario: 无参数补全命令

- **WHEN** 输入 `/copy ` （或任意无参数补全的命令）并带空格
- **THEN** 不出现候选菜单，输入保持普通编辑
