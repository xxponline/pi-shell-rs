# Proposal

## Why

会话树目前只有 5 种过滤模式与折叠导航，面对长会话/多分支树时只能靠上下滚动逐行找目标；pi 的树选择器支持**即时文本搜索**（可打印字符直接输入、空白分词 AND 匹配），这是长树定位的核心操作。差异表 #7 后续批次中"树内搜索"是第一个待做项。

## What Changes

- 树面板进入**搜索模式**：可打印字符直接追加到搜索查询（不关闭面板、不落输入框），Backspace 删字符，Esc 先清空查询再按才关闭面板——与 pi `TreeSelector` 键序一致
- 查询按**空白分词、全部 token 命中（AND）、大小写不敏感子串**过滤树节点；可搜索文本覆盖节点上 pi `getSearchableText` 对等的字段（会话名、首条消息预览、bash 命令、模型/thinking 变更等，按我们树节点实际携带的数据裁剪）
- 搜索与既有 5 过滤模式、折叠状态**正交叠加**（先过滤模式、再搜索、再折叠裁剪）；空结果时保留选中语义
- 树面板状态行显示当前查询（带 token 数/命中数），命中为空给出明确提示
- **不做**：树内标签编辑（shift+L）——已按差异 #14 三重排除并写入 `Docs/pi-tui-interaction.md`

## Capabilities

### New Capabilities

（无）

### Modified Capabilities

- **session-management**：新增“树内搜索”需求（ADDED）——搜索输入键序、分词匹配语义、与过滤/折叠的叠加、状态行展示（树浏览主需求在该能力下）
