# file-completion Specification

## Purpose

输入 `@文件` 引用时提供即时候选：从当前工作目录递归发现文件路径、按相关度排序展示，一键应用到输入框并保持路径续写能力，使用户无需记忆或手打完整文件路径即可完成文件引用。

## ADDED Requirements

### Requirement: `@` token 触发与提取

编辑器输入中光标前存在以 `@` 起始的 token（`@路径` 或 `@"带引号路径"`，token 以空白/分隔符起始）时 MUST 打开文件补全菜单；光标移出该 token、token 被删除或输入提交时 MUST 关闭。token 提取 MUST 支持未闭合引号形态（`@"src/ma` 视为 `@"src/ma` 前缀）；普通斜杠命令 token（`/...`）不触发本菜单。

#### Scenario: 输入 @ 即触发

- **WHEN** 输入框为空或已有文本，键入 `@`
- **THEN** 打开文件补全菜单并列出 cwd 下的顶层候选，输入框内容不变（`@` 保留）

#### Scenario: 续输即重过滤

- **WHEN** 菜单打开时继续键入 `src/`
- **THEN** token 变为 `@src/`，候选即时刷新为该目录内容/匹配项

#### Scenario: 引号形态

- **WHEN** 输入 `@"my fi`
- **THEN** 菜单以 `my fi` 为查询前缀继续提示，不因空格中断 token

### Requirement: 候选生成

候选 MUST 由两部分合并去重：① **基础目录候选**——按 token 中目录部分定位搜索目录（相对 cwd、支持 `~` 与绝对路径；以 `/` 结尾则列该目录），条目为大小写不敏感 `startsWith` 前缀匹配；② **递归模糊候选**——当系统存在 `fd` 时按查询递归搜索（对齐 pi：打分 文件名精确 100 / startsWith 80 / 文件名子串 50 / 路径子串 30、目录 +10；排序 分数降序→路径深度→长度→字典序）。合并后 MUST 去重并**截取前 20**；`fd` 缺失时仅保留基础目录候选。搜索目录不存在或不可读 MUST 返回空候选（静默，无错误提示）。

#### Scenario: 前缀与排序

- **WHEN** token 为 `@src/` 且该目录含 `lib`、`app.rs`、`main.rs`
- **THEN** 候选按目录优先、字母序列出，目录项带 `/` 后缀

#### Scenario: 模糊命中深层文件

- **WHEN** `fd` 存在且输入 `@login`，深层路径 `src/auth/login.ts` 匹配
- **THEN** 该候选出现且排序分高于仅路径包含的弱匹配项，总数不超过 20

#### Scenario: fd 缺失回落

- **WHEN** 系统无 `fd` 且输入 `@src`
- **THEN** 仍展示基础目录前缀匹配候选（如 `src/`），无报错

### Requirement: 菜单应用与键位

菜单键位 MUST 复用 `slash-autocomplete` 的菜单约定（↑↓ 移动选中、Tab 应用、回车应用并提交该行、Esc 只关菜单、继续输入即时重过滤）。应用时 MUST 保留 `@` 前缀：选中**文件**补一个空格结束 token；选中**目录**不补空格且光标置于目录名后（可继续下钻）；`~/`、`./`、绝对路径写法 MUST 保留；含路径分隔符的候选 MUST 自动包上 `@"..."` 引号；光标落位于插入文本之后。应用后 MUST 关闭菜单。

#### Scenario: 选择文件应用

- **WHEN** 菜单选中 `src/main.rs` 按 Tab
- **THEN** 输入变为 `@src/main.rs `（文件后带空格），光标在空格后，菜单关闭

#### Scenario: 选择目录续写

- **WHEN** 菜单选中目录 `src/` 按 Tab
- **THEN** 输入变为 `@src/`（无空格），光标在 `/` 后，菜单关闭，可继续输入子路径

#### Scenario: 回车应用并提交

- **WHEN** 菜单打开且回车被按下
- **THEN** 选中候选先应用到输入框，随后该行按普通提交流程发送（文件引用随消息进入模型上下文），输入框清空
