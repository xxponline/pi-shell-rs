# session-management Delta

## ADDED Requirements

### Requirement: 树内搜索

会话树浮层 MUST 支持即时文本搜索：浮层内可打印字符直接追加到搜索查询（不关闭面板、不进入输入框提交流），Backspace 删除查询末字符；Esc MUST **先清空非空查询**（保持面板与选择）、查询已空时才关闭面板。查询 MUST 按空白分词，**所有 token 同时命中**（AND）、大小写不敏感的子串匹配；可搜索文本覆盖节点携带的会话名、消息预览、bash 命令等展示字段。搜索 MUST 与既有过滤模式、折叠状态正交叠加（先过滤模式、再搜索、再折叠裁剪）；查询非空时状态行 MUST 展示查询与命中数，零命中给出明确提示且不崩溃、不丢失原选择语义。

#### Scenario: 输入即搜

- **WHEN** 树浮层中依次键入字符 `ref`（非导航键、非斜杠命令）
- **THEN** 面板保持打开，查询为 `ref`，仅显示可搜索文本命中 `ref` 的节点（含父链上下文结构完整）

#### Scenario: 分词 AND 匹配

- **WHEN** 查询为 `login error`（含空白）
- **THEN** 仅显示同时包含 `login` 与 `error`（大小写不敏感）的节点；单命中一个词的节点被过滤

#### Scenario: Esc 先清搜索再关面板

- **WHEN** 查询非空时按一次 Esc
- **THEN** 查询清空、过滤恢复、面板仍打开且选择保持；再次按 Esc 才关闭面板

#### Scenario: 与过滤模式和折叠叠加

- **WHEN** 过滤模式为 user-only、部分子树折叠，再输入查询
- **THEN** 可见集合 = 过滤模式通过 ∧ 搜索命中 ∧ 未被折叠裁剪；切换 ctrl+o 过滤模式时查询保持不变

#### Scenario: 零命中提示

- **WHEN** 查询无任何命中
- **THEN** 状态行显示查询与 0 命中提示，列表为空但面板可用，Backspace 逐字恢复结果
