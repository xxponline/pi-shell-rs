# Spec Delta

## ADDED Requirements

### Requirement: 文本选区与反视频高亮

在消息区**背景**（非滚动条列、非 thinking/工具卡组件行、浮层关闭时）
按下左键并拖动 MUST 产生文本选区：以绝对屏行与显示列为坐标、字符粒度
跨行扩展；选中内容 MUST 以反视频（前景/背景互换、其余样式保留）高亮。
无拖动的纯点击 MUST NOT 产生选区。拖拽指针贴近视口上/下缘时 MUST 自动
滚动并让选区随内容延伸，离开边缘或释放后停止。

#### Scenario: 拖拽选区与反视频高亮

- **WHEN** 在消息区背景按下左键并拖过若干行后释放
- **THEN** 拖过的文本以反视频高亮（样式保留、仅前景背景互换）；期间
  从未拖动的纯点击不产生选区

#### Scenario: 边缘拖拽自动滚动

- **WHEN** 按住左键拖拽到视口顶部或底部边缘附近并停留
- **THEN** 消息区自动滚动、选区随滚动继续延伸；离开边缘或释放后停止

### Requirement: 选区粒度双击词与三击行

500ms 连击窗口内双击 MUST 选中词、三击 MUST 选中整行（须同行同词边界）；
词边界 MUST 含 `/ - + \ ~ _ .` 连接符使路径片段整体可选。粒度确定后拖拽
MUST 按词/行延展而非逐字符。

#### Scenario: 双击选词与三击选行

- **WHEN** 500ms 内双击一个词（或含连接符的路径片段），随后拖拽
- **THEN** 该词（或整个路径片段）被选中，拖拽按词粒度延展；三击选中
  整行并按行延展；超时或跨行的再次按下重置为字符粒度

### Requirement: 选中自动复制

鼠标释放时若选区非空 MUST 自动复制选中文本并显示绿色 `Copied!` 提示；
选区为空 MUST 不复制、不提示。复制文本 MUST 为各选中行按显示列切片后的
内容、行间以换行连接、行尾空白去除、不含任何 ANSI 样式序列。

#### Scenario: 释放即复制与空选区

- **WHEN** 拖拽产生非空选区后释放鼠标；或按下后从未拖动
- **THEN** 前者复制选中文本并出现 `Copied!`；后者不复制、无提示

#### Scenario: 复制内容为选区文本

- **WHEN** 选中跨多行（含工具卡/thinking 渲染行）后释放
- **THEN** 复制文本为各行按显示列切片的内容、`\n` 连接、行尾去空白、
  无 ANSI 序列

### Requirement: 选区优先级与清除

滚动条列按下 MUST 维持滚动条既有语义（优先级高于选区）；点击
thinking/工具卡组件行 MUST 照常执行其点击语义并**清除选区**；浮层打开
时 MUST NOT 开始选区。会话切换或重建 MUST 清除选区（选区坐标指向被
替换的内容）。既有滚动条瞬态显隐、卡片/thinking 单块切换交互 MUST
保持不变。

#### Scenario: 组件与滚动条优先于选区

- **WHEN** 在 thinking/工具卡行上按下左键，或在滚动条列上按下
- **THEN** 前者执行组件点击语义并清除既有选区；后者维持滚动条语义，
  均不开始新选区；浮层打开时背景按下不产生选区

#### Scenario: 会话切换清除选区

- **WHEN** 会话切换或重建（get_messages 应答替换 transcript）时存在选区
- **THEN** 选区与高亮立即清除
